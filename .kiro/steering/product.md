# Product Overview

NyieunTudu is a client-side task manager web application. Users can create tasks with a name, deadline date, and priority level (High, Medium, Low). Tasks can be filtered by status (All, Active/Success, Completed), marked as complete, edited, deleted, or restored.

Data is persisted in the browser via localStorage. There is no backend server or database.

The app supports a dark theme toggle accessible from the header navigation.
